# Autocomplete and Autocorrect

**OIBSIP Data Analytics — Level 2**

## Objective
Build a simple n-gram autocomplete and edit-distance autocorrect demonstration from a small educational text corpus.

## Files
- `Autocomplete_Autocorrect.ipynb` — Jupyter Notebook analysis.
- `text_corpus.txt` — synthetic educational practice data included with this repository.

## Run locally
From this project folder, install the repository requirements and launch Jupyter:

```bash
python -m pip install -r ../requirements.txt
jupyter notebook
```

Open `Autocomplete_Autocorrect.ipynb` and run the cells from top to bottom. Run the notebook with this folder as the working directory so its relative dataset paths resolve.

## Dataset and interpretation
The included data is synthetic and is provided only for practice. Results are not real business findings and the data is not represented as an official Kaggle/UCI dataset. Replace it with a suitable public dataset, cite its source and licence, rerun the analysis, and independently verify all findings before presenting this as real-world analysis.
